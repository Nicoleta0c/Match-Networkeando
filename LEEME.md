# Cómo abrir este proyecto en Claude Code

1. Descomprime `networkeando-rd.zip` en una carpeta de tu computadora (por ejemplo, Documentos).
2. Abre Claude Code: en la app de escritorio, pestaña **Code**, elige la carpeta `networkeando-rd`. O en la terminal: `cd networkeando-rd` y luego `claude`.
3. Las skills ya vienen instaladas en `.claude/skills/` (es una carpeta oculta). Si no las ves en Claude Code, escribe `/skills` para revisarlas o reinicia Claude Code.
4. Primer mensaje sugerido para Claude Code:

   > Lee CLAUDE.md. Primero corre la app en local y verifica que el modo demo funciona. Luego propónme cómo conectar la base de datos (Firebase o Supabase) para que los perfiles se compartan entre todos en el evento, y espera mi respuesta antes de instalar nada.

Para ver la app sin instalar nada, abre `index.html` en el navegador y entra en `#demo` (por ejemplo `index.html#demo`).
